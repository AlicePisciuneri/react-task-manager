# 🗂️ Task Manager – React Web App

Applicazione web per la gestione di task con stato dinamico, pensata per simulare un flusso reale di organizzazione delle attività.

## ✨ Cosa permette di fare

- Visualizzare una lista di task  
- Aggiornare lo stato delle attività (To do / Doing / Done)  
- Gestire i task in modo dinamico con aggiornamento dell’interfaccia in tempo reale  
- Interagire con dati tramite API REST  

## 🧠 Perché questo progetto

Questo progetto nasce per mettere in pratica una logica molto concreta, creare strumenti che aiutino davvero a organizzare il lavoro.

È un primo passo verso applicazioni più strutturate che gestiscono dati e interazioni reali.

## ⚙️ Tecnologie utilizzate

- React
- JavaScript
- CSS
- REST API
- JSON
